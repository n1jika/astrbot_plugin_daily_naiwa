# 今日奶娃

AstrBot 群聊插件：每天抽取一张奶娃图片，收集自己的图片图鉴。

## 使用

- `/今日奶娃`：每日第一次随机抽取一张图片；同一天再次使用会返回原结果。同一消息平台上的同一个用户在不同群聊共用结果和图鉴。
- `/奶娃图鉴`：查看收集进度和图鉴，已收集显示图片，未收集显示 `?`。
- `/奶娃图鉴 2`：查看第 2 页；每页 16 项。

日期按北京时间（UTC+8）计算，每天零点重置抽取机会。不同消息平台的用户 ID 分开保存；此插件仅处理群聊。

## 安装和配置

1. AstrBot 版本需支持 `file` 类型插件配置（文档标注 4.13.0 起支持）。在插件页面通过仓库链接安装本插件，并确认 Pillow 依赖安装成功。
2. 打开本插件的配置，在「奶娃素材图片」中上传 PNG、JPG、JPEG 或 WebP 图片，保存配置后重载插件。
3. 在群聊中使用 `/今日奶娃` 和 `/奶娃图鉴`。如果更改了唤醒前缀，请使用实际配置的前缀。

图片按内容去重。素材导入后会保留独立快照：从配置移除的图片不再参加新抽取，但此前抽到的用户仍能在图鉴看到它，当天已经抽过的结果也会保留。覆盖同名上传文件会按新图片处理；修改配置后请保存并重载。单张上传图片上限为 20 MB。

## 数据和维护

SQLite 数据库、图片快照和图鉴缓存位于 AstrBot 的 `data/plugin_data/astrbot_plugin_daily_naiwa/`；备份或迁移时请保留整个目录。插件不自带素材，请自行上传有权使用的图片。删除插件数据将清除抽取记录和图鉴。

如果命令无响应，检查插件是否启用、当前会话配置是否允许该插件、群聊前缀和 AstrBot 日志。具体平台的图片发送和热重载行为需要在目标环境中验证。
